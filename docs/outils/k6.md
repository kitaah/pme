# k6

## Fiche d'identité

| Information | Détail |
|---|---|
| **Rôle** | Mesure la rapidité et la fiabilité de l'API quand plusieurs utilisateurs s'en servent en même temps |
| **Version** | k6 1.4.0 dans la pipeline ; dernière version du dépôt officiel sur le poste (`k6 version` l'affiche) |
| **Adresse en local** | aucune |

## Description

k6 est un outil libre de test de charge, édité par Grafana Labs. Il simule des utilisateurs qui se connectent, déposent
des annonces et consultent les leurs. Il mesure les temps de réponse et le nombre d'erreurs. Les scénarios sont écrits
en JavaScript. Le test réussit ou échoue selon des seuils fixés à l'avance.

**Définitions**

- **Test de charge** : test qui envoie beaucoup de demandes à une application pour vérifier qu'elle reste rapide.
- **Utilisateur virtuel** : utilisateur simulé par k6, qui répète un scénario en boucle.
- **Seuil** : limite à ne pas dépasser, par exemple moins de 500 ms de temps de réponse. Si elle est dépassée, k6 signale
  un échec.
- **Percentile 95** : durée en dessous de laquelle se situent 95 % des réponses.

## Rôle dans le projet

- Il vérifie que l'API reste rapide avec 20 utilisateurs simultanés qui déposent et consultent des annonces.
- Il prouve que le dépôt d'une annonce ne dépend pas du service de modération : le temps de réponse reste le même quand
  ce service est arrêté.
- Il tourne dans la pipeline GitLab avec un profil léger : 10 utilisateurs pendant 1 minute, sur l'API démarrée dans le job.
- Dans la pipeline, il n'utilise pas Keycloak : un faux fournisseur d'identité signe le jeton de test.
- Sans lui, aucune mesure ne confirme que les réglages de performance (nombre de pods, connexions à la base) suffisent.

## Fichiers et dossiers principaux

| Fichier ou dossier | Description |
|---|---|
| `tests/performance/load.js` | Scénario de charge : deux profils (complet et ci), avec leurs seuils. |
| `tests/performance/decoupling.js` | Scénario qui prouve l'indépendance entre le dépôt et la modération. |
| `tests/performance/common.js` | Fonctions partagées : connexion, dépôt et lecture des annonces. |
| `tests/performance/support/ci-environment.cjs` | Faux fournisseur d'identité et flux NATS pour la pipeline. |
| `scripts/perf-ci.sh` | Lance l'API, le jeton de test et k6 dans la pipeline. |
| `scripts/perf-decoupling.sh` | Lance le scénario deux fois, avec puis sans le service de modération. |
| `.gitlab-ci.yml` | Définit le job `performance-tests` de la pipeline. |
| `Makefile` | Contient les commandes d'installation et de lancement. |

## Commandes essentielles

À lancer dans un terminal, depuis le dossier du projet, Minikube démarré et la plateforme déployée.

| Commande | Description |
|---|---|
| `make k6-install` | Installe k6 sur Debian, Ubuntu ou Linux Mint, une seule fois. |
| `make perf-prepare` | Relève la limite de débit par adresse IP, sinon k6 reçoit des erreurs 429. |
| `make perf-load` | Lance le test de charge, qui dure environ 1 min 45. |
| `make perf-decoupling` | Lance le test d'indépendance entre le dépôt et la modération. |
| `make perf` | Lance les deux tests à la suite. |
| `make perf-reset` | Remet la limite de débit normale. |

!!! tip "Astuce"
    Pendant le test, ouvrir Grafana avec `make grafana`, et suivre la charge des pods avec
    `kubectl -n pme top pods`. Un pod proche de sa limite de mémoire (256 Mi) est le signe à repérer.

!!! warning "Attention"
    Toujours lancer `make perf-reset` après les tests. Sans cela, la limite de débit reste relevée et l'API n'est plus
    protégée contre les abus.

!!! note "À savoir"
    Le certificat de l'ingress est signé par l'autorité locale du projet, que k6 ne connaît pas. La commande
    `make perf-load` désactive donc la vérification du certificat. Cette option est réservée à ce test local.

!!! note "À savoir"
    Le test échoue, avec le code de sortie 99, si un seuil est dépassé : moins de 1 % d'erreurs, et un percentile 95 sous
    500 ms. Dans la pipeline, il bloque donc le job `performance-tests`. Voir la page
    [Tests de performance](../pipeline/tests-performance.md).
